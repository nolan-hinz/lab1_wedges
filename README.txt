Run the python file "image_correction.py"

Change the filename variable every time until you have done all of the image corrections for the wedges.

When you run the script, the image will pop up. When it pops up, make it fullscreen to see it better. Then click the tip of the wedge, then click the top right corner of the wedge, then click the bottom right edge of the wedge. 
	- this part can be finicky and you may need to do it a couple of times before it works.
	- In the command window or terminal you are running from it should prompt you to accept or decline the image, accept if the thickness looks about the same as in the windoff image.

Repeat until you do all of the images.
